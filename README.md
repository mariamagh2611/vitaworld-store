# متجر مورد

قالب مجاني لإنشاء متجر إلكتروني للدفع عند الاستلام، مرتبط بمنصة مورد. يمكنك تخصيص منتجاتك وأسعارك ومظهر متجرك من لوحة الإدارة بالعربية أو الفرنسية أو الإنجليزية.

اضغط **Deploy to Cloudflare** لإنشاء متجرك الخاص.
